# Data Formats

This section details some of the data formats we use for storing data. This includes 

* [NWB](https://nwb.org/) files for physiology and behavior data
* [anndata](https://anndata.readthedocs.io/en/latest/) files for annotated matrix arrays, used commonly for transcriptomic and cell type data.
* SWC files for morphology skeletons

In addition to these community based data file standards, we use the [aind-data-schema](https://github.com/AllenNeuralDynamics/aind-data-schema) to document rich metadata for each asset. 

Each of these are outlined in the subsequent pages.
