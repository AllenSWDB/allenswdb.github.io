# Dynamic Routing Task Overview

The dynamic routing task involves a visual–auditory switching task in which the rewarded sensory modality alternates within a session, requiring mice to dynamically route sensory information to appropriate motor outputs depending on behavioral context. During the session, mice receive intermingled auditory and visual stimuli. During alternating blocks, the mice are rewarded for responding correctly to the auditory or visual stimulus.

For each modality, auditory and visual, there is a rewarded stimulus condition and an unrewarded condition. For example, a vertically oriented visual grating stimulus is rewarded (in the visual block), but a horizontally oriented grating stimulus is not rewarded in any block. The vertical grating is a target stimulus, the horizontal grating is a non-target stimulus. All stimulus conditions are presented across the entire session, but the reward contingency is dependent on the block.
